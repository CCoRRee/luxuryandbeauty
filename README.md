# LuxBeauty (projeto acadêmico)

Site informativo sobre **produtos cosméticos femininos de luxo**, com tópicos de marcas como:
Fenty Beauty, Dolce & Gabbana, Chanel (Coco Chanel), Prada, Victoria’s Secret, Christian Louboutin Beauty, Dior, Louis Vuitton e Bottega Veneta.

## Como abrir

1. Abra o arquivo `index.html` no navegador (Chrome/Edge/Firefox).
2. Use a busca e o filtro de categoria para navegar pelas marcas.

## Imagens

As imagens em `assets/` são **ilustrações genéricas** (sem logotipos) criadas apenas para complementar cada tópico.

### Logos das marcas (opcional)

Por questão de direitos autorais/marca, este projeto **não inclui** logos oficiais.  
Se você tiver permissão para usar as logos, coloque os arquivos (PNG com fundo transparente recomendado) em `assets/logos/` com estes nomes:

- `assets/logos/fenty-beauty.png`
- `assets/logos/dolce-gabbana.png`
- `assets/logos/chanel.png`
- `assets/logos/prada.png`
- `assets/logos/victorias-secret.png`
- `assets/logos/christian-louboutin.png`
- `assets/logos/dior.png`
- `assets/logos/louis-vuitton.png`
- `assets/logos/bottega-veneta.png`

Se algum arquivo não existir, o site volta automaticamente para a ilustração genérica correspondente.

## Observação

Este é um projeto **informativo/educacional** e **não oficial**. Marcas e nomes citados pertencem aos seus respectivos proprietários.
